# رفيق الحفظ

تطبيق ويب عربي لحفظ القرآن الكريم ومراجعته.

## ما الذي يفعله

- **الحفظ**: كل سورة مقسّمة إلى مقاطع قصيرة. تقرأ المقطع، تستمع إليه مع تكرار كل آية، ثم تخفي النص (كله أو ما عدا أول كلمة من كل آية) وتتلو من حفظك، وتضغط على الآية لكشفها.
- **المراجعة**: كل مقطع تحفظه يدخل جدول مراجعة بالتكرار المتباعد: بعد يوم، ثم ثلاثة أيام، ثم تتباعد المواعيد كلما ثبت الحفظ، وتقترب إذا تعثّرت.
- **الاختبار**: أسئلة «ما الآية التالية؟» و«أكمل الآية» من محفوظاتك أو من سورة تختارها.
- **المتابعة**: عدد الآيات المحفوظة، نسبة التقدّم، الأيام المتتالية، ونسخة احتياطية تُنسخ وتُلصق.

التقدّم يُحفظ في المتصفح (localStorage) ولا يُرسل إلى أي خادم.

## التشغيل

التطبيق ملفات ثابتة بلا خطوة بناء. شغّله عبر أي خادم ويب:

```
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`. يصلح للنشر كما هو على GitHub Pages.
